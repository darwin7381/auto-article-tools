# Console 體驗藍圖 —— 「取代 BD/DM/編輯的系統」該展示什麼、該有哪些功能

> 2026-07-02,依 Joey 指示從功能與展示面重新徹底思考。
> 前提:這不是「內容工具」,是要**徹底取代 Notion 兩張表 + DM 職位、讓部門自己跑**的作業系統。
> 評斷每個頁面/功能的唯一標準:**它有沒有讓「人被取代」這件事看得見、用得動。**

---

## 0. 核心診斷

現在的 console 是**按資料類型組織的工具箱**:看板(tasks)、廣告版位(slots)、Jobs(pipeline runs)。
功能都對,但它回答的問題是「資料在哪」,不是部門實際運作要回答的三個問題:

1. **今天誰要幹嘛?**(人的待辦 —— 只剩 BD 和編輯部兩種人)
2. **AI 正在幹嘛 / 幹了什麼?**(取代 DM 的那個「看不見的員工」要看得見,才有信任、才敢放手)
3. **生意跑得怎樣?**(額度消耗、到期、產出 —— 管理者視角)

「取代人的系統」的首頁不該是工具,該是**指揮中心**:打開就看到部門自己在跑。

## 2. 展示藍圖(頁面級,依優先序)

### P0 —— 指揮中心(新首頁,取代「處理稿件」當首頁)
**這是整個系統的敘事核心:打開 → 看到部門自己在跑。** 後端 API 已全備(digest / board / activity),純前端頁。

- **今日總覽帶**:晨報視覺化(進行中 N 件、逾期、今日截止、今日排程發佈、Banner 到期)—— `GET /board/digest` 已有。
- **待人動作雙佇列**:「待 BD」「待編輯部」兩列卡(從細狀態聚合:awaiting_bd_close / client_review → BD;awaiting_upload / draft_done / awaiting_line → 編輯部),點卡直達抽屜。**人只看這裡就知道今天要幹嘛。**
- **AI 活動 feed**:全板 activity 串流裡 actor=system 的事件(自動移欄、自動通知、billed、心跳提醒),即時滾動 —— 「看不見的員工」變看得見。
- **預警帶**:合約到期 / 額度剩 ≤1 / 逾期紅點。
- **pipeline 健康橫條**:8 欄各幾件、哪欄超 WIP。

### P0.5 —— 看板「角色鏡頭」
看板工具列加一個視角切換(全部 / 待 BD / 待編輯部):按細狀態過濾的 preset,一鍵變成「我的工作佇列」。便宜、立刻有感。

### P1 —— 客戶 360(新頁)
BD 對客戶的單一畫面:選客戶 → 所有合約與額度用量、進行中/歷史稿件、發佈連結、佔用的版位檔期。
(client 目前是字串;第一版直接按字串聚合即可,不用先建 Client 實體。後端加一個 aggregate endpoint。)

### P1 —— 發佈行事曆(新頁或併入指揮中心)
所有稿件的 scheduled_publish_at / publish_deadline / Banner 檔期,月曆視圖 —— 編輯部「今天/這週要發什麼」。版位頁的甘特已好,這是內容側的對應物。

### P2 —— 營運矩陣(管理者)
全客戶 × 合約 × 品項額度的即時矩陣(設計文件 4.2 的「全局即時矩陣」),含月產出統計。合約 modal 升級成頁。

### P2 —— 自動化率(「滅 DM」的量化證明)
每張卡:activity 裡 system vs 人的動作比 → 「這件 12 步,10 步自動」。全局:零人工碰過的案件 %。
**這是對「取代人」最有說服力的展示**,資料已在 DB,只差聚合與呈現。

### 展示配套 —— Demo 資料 seed
現在板上只有零星測試卡,展示時看板/晨報/預警全是空的。要一個 `POST /board/seed-demo`(或腳本):
種 8-10 個客戶、3-4 份合約(有的額度快用完、有的快到期)、15-20 張卡鋪滿各狀態(含逾期、今日截止、今晚 LINE、banner 到期)—— 讓每個視圖第一眼就是活的。

## 4. 建議動工順序(功能與展示交錯,每步都可獨立驗收)

1. **指揮中心 + demo seed**(P0,純前端 + 一個 seed endpoint;agy 主設計)—— 先讓系統「看起來就是在自己跑」。
2. **看板角色鏡頭**(P0.5,順手)。
3. **B 線 AI 初稿**(F0,後端 workflow + 卡片觸發)—— 補掉最大功能缺口,三條線都有 AI。
4. **客戶 360 + 發佈行事曆**(P1)。
5. **Banner 檔期↔版位雙向同步 + 規格驗證**(F1)。
6. 之後:營運矩陣、自動化率、Sheets、進件、通知啟用。
